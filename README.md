# לומדים מהדף

אפליקציית ווב (PWA) ללימוד: מצלמים דפי לימוד, והאפליקציה בונה מהם כרטיסיות, שאלות אמריקאיות, התאמת זוגות, סידור אותיות, גדולות וקטנות, כתיבה, שיעור קצר וקישורים לסרטונים ביוטיוב.

- כל אחד יכול לפתוח את האפליקציה, בלי חשבון Claude.
- הסטים נשמרים בטלפון של כל משתמש, והתרגול עובד גם בלי אינטרנט.
- כדי לשתף סט, לוחצים על כפתור השיתוף בתוך הסט. הסט כולו נשלח בתוך הקישור.
- את הקריאה של הדפים עושה Claude דרך ה-API, עם המפתח שלך. המפתח נשאר בשרת ולא מגיע לטלפונים.

## מה צריך

1. **מפתח API של Anthropic.** נכנסים ל-console.anthropic.com, מוסיפים אמצעי תשלום, ואז API Keys ← Create Key. מומלץ להגדיר תקרת הוצאה חודשית ב-Limits.
2. **חשבון Vercel חינמי:** vercel.com.

## העלאה עם Vercel CLI (הכי מהיר)

```bash
cd lomdim-mehadaf
npx vercel login
npx vercel link            # יוצר פרויקט חדש
npx vercel env add ANTHROPIC_API_KEY production
# לא חובה: קוד גישה, כדי שרק מי שמכיר אותו יוכל ליצור סטים
npx vercel env add ACCESS_CODE production
npx vercel --prod
```

בסוף תקבל כתובת כמו `https://lomdim-mehadaf.vercel.app`.

## העלאה דרך GitHub (בלי טרמינל)

1. יוצרים repo חדש ב-GitHub ומעלים אליו את כל הקבצים מהתיקייה.
2. ב-Vercel: Add New ← Project ← בוחרים את ה-repo.
3. תחת Environment Variables מוסיפים `ANTHROPIC_API_KEY`, ואם רוצים גם `ACCESS_CODE`.
4. לוחצים Deploy.

## משתני סביבה

| משתנה | חובה | מה זה |
|---|---|---|
| `GEMINI_API_KEY` | אחד מהשניים | מפתח חינמי מ-aistudio.google.com (מועדף אם קיים) |
| `ANTHROPIC_API_KEY` | אחד מהשניים | מפתח Claude בתשלום מ-console.anthropic.com |
| `ACCESS_CODE` | לא | אם מוגדר, האפליקציה תבקש את הקוד לפני יצירת סט. תרגול לא צריך קוד. |
| `ANTHROPIC_MODEL` | לא | ברירת המחדל: `claude-sonnet-5-5` |
| `HOURLY_LIMIT` | לא | כמה בקשות בשעה מכל כתובת. ברירת המחדל: 40 |

אחרי שינוי של משתנה סביבה צריך לעשות Redeploy.

## התקנה בטלפון

- **אייפון (Safari):** פותחים את הכתובת ← כפתור השיתוף ← "הוסף למסך הבית".
- **אנדרואיד (Chrome):** פותחים את הכתובת. מופיע באנר "התקן את האפליקציה", או דרך שלוש הנקודות ← "התקנת אפליקציה".

## הרצה מקומית

```bash
npx vercel dev
```

## מבנה

```
index.html            מסך האפליקציה
style.css             עיצוב (בהיר וכהה)
app.js                כל הלוגיקה: מצבי תרגול, שמירה בטלפון, שיתוף בקישור
sw.js                 עבודה בלי אינטרנט
manifest.webmanifest  הגדרות ההתקנה למסך הבית
icon-*.png, maskable-512.png, apple-touch-icon.png   אייקונים
api/generate.js       השרת: שולח את התמונות ל-Claude ומחזיר JSON
vercel.json           זמן ריצה מקסימלי לשרת (120 שניות)
```

## עלות

כל יצירה של סט היא קריאה אחת ל-Claude לכל שלושה דפים בערך. התשלום לפי השימוש בחשבון ה-API שלך. תרגול, שיתוף ופתיחה של סטים לא עולים כלום.
